Restore from a Backup

Choose a backup JSON file created by The Student Hub. Restoring updates the keys included in that file. Other saved keys are left untouched.

Privacy: The backup is downloaded to your device. This page does not upload it to a server. Keep the file private because it may contain personal study information.

This tool supports only the storage keys listed in its code. When we add more saved features, we must update that list too.
